更新本地数据

方式一　抓取书签 推荐 · 所有人可用

用你自己的登录态在后台页面抓取，抓完直接下载 _raw.json。 全程不传 Cookie、不上传任何数据 —— 数据只落在你自己的硬盘。
📌 抓取 tagsearch 数据
  1. 安装：把上面那个按钮 拖到书签栏；或右键它 →「添加到收藏夹 / 添加书签」（最稳）。
    　 也可以点「复制书签代码」，再手动新建书签、把代码粘进「网址」栏 —— 粘贴后检查开头是否还有 javascript:，被浏览器吃掉就手动补上。
  2. 打开并登录 partner.dota2.com.cn 后台任意页面。
  3. 点一下书签栏里的「抓取 tagsearch 数据」，右下角显示进度，跑完浏览器会自动下载 _raw.json。
  4. 回到本页，用下面方式二选中刚下载的 _raw.json；载入后会再导出一份 data.js，覆盖本目录同名文件即可长期免抓。

方式二　选择文件载入 已有 data.js 或 _raw.json

支持 _raw.json（书签抓取的原始结果）与 data.js；成功后会自动下载一份最新 data.js。

更新本地图标

一、复制的目标目录 只取 panorama\images 下这三个一级目录里的 png

目录（从 → 复制到）放什么文件名要求
panorama\images\spellicons\ → icons\spellicons\英雄技能、野怪 / 建筑 / 召唤物技能图<技能代码名>_png.png
panorama\images\items\ → icons\items\物品技能图（神符、魔晶 / 神杖升级等）<道具代码名>_png.png
panorama\images\heroes\ → icons\heroes\英雄 / 中立单位小图标<单位代码名>_png.png
技能代码名＝后台技能列表里的英文名（如 antimage_mana_break、bottle_shield）， 文件名必须是「代码名 + _png.png」，多一个字母都认不出。

二、操作步骤

  1. 把 png 复制进 D:\wiki\tagsearch\icons\ 对应子目录，文件名不要改（改了就按新名字找）。
  2. 重建并刷新：回 tagsearch 目录双击 rebuild.bat（等价于下面那三条命令），跑完回本页按 F5。
顺序不能换：local_icons.py 读的是 data.js，必须先 build_data.py 让它看到最新技能表， 否则新技能拿不到图。
第 2 步会顺带重建 icons_b64.js（约 7MB）：那是给双击打开 index.html（file://）时截图用的 图标内联包 —— 浏览器不允许 file:// 页面读本地图片像素，只能把图标预先变成 data: 再塞进图里。 少了它，双击打开截图会提示「缺少 icons_b64.js」。
想手敲命令的话别直接敲 python：cmd 里它常常指向 Cygwin 的 3.6（没有 Pillow，会报错）， 双击 rebuild.bat 会自动挑一个可用的 Python。

三、图名和代码名对不上怎么办

  1. 长期生效：在 scripts\icon_overrides.json 里加一行 "技能代码名": "图标名" （例 "Activate Shield Rune": "bottle_shield_png"），重建后全库按它取图。
  2. 临时指定：在缺图清单 md 的「图片名称」列填图标名，脚本同样会读（可少写 _png）。
  3. 确实没有专属图：什么都不用放，技能会自动用 other_icons\dota2_exe_png.png； 先天技能用 other_icons\innate_icon_png.png。想换这两张，直接覆盖同名文件即可，全库立即生效。
  4. 查还缺什么：看 icons\missing.json，"count": 0 表示每条技能都有图了。
